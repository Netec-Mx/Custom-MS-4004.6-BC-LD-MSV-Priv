# Capacita a tus empleados con Microsoft 365 Copilot: Casos de uso Gestión del Talento y Sostenibilidad

Te damos la bienvenida a la **plataforma de laboratorios**. Aquí podrás explorar diferentes tecnologías a través de prácticas guiadas. ¡Desarrolla tus habilidades y lleva tus conocimientos al siguiente nivel!

Este curso proporciona a profesionales de Gestión del Talento y Sostenibilidad una experiencia práctica para utilizar Microsoft 365 Copilot y agentes como apoyo en análisis de necesidades, interpretación de información agregada, diseño de iniciativas y seguimiento de indicadores. El caso transversal evita decisiones automatizadas sobre personas y enfatiza validación, contexto y uso responsable de la información. La sesión utiliza la fórmula Contexto + Objetivo + Origen + Expectativas, los agentes Investigador y Analista y las aplicaciones Excel, Word, PowerPoint y Outlook para convertir hallazgos en iniciativas, indicadores y comunicaciones adaptadas a diferentes públicos.
