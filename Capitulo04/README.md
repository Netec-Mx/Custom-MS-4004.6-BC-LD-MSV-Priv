# Laboratorio 4: Comunicar acciones a diferentes grupos de interés

**Duración:** 15 min

## Descripción
Con Copilot en Outlook generarán una comunicación para líderes y otra para colaboradores o grupos de interés, ajustando profundidad, tono, acciones esperadas y datos que corresponde compartir.

## Pasos para ejecutar la práctica

1. **Redacción de comunicaciones diferenciadas en Outlook:**
   * Abre **Microsoft Outlook** (o Copilot Chat) y adjunta el documento `Propuesta_Intervencion_Talento.docx`.
   * Envía el siguiente prompt para generar el primer borrador:
     ```text
     Con base en el archivo adjunto Propuesta_Intervencion_Talento.docx, redacta un correo ejecutivo dirigido al Comité de Liderazgo enfocándote en ROI, decisiones requeridas, recursos e indicadores ESG.
     ```
   * En el mismo chat, envía la orden para la segunda audiencia:
     ```text
     Con base en el mismo documento, redacta una versión de comunicado general dirigida a todos los colaboradores con un tono motivador, enfocado en los beneficios directos para la experiencia del empleado y el impacto positivo en sostenibilidad.
     ```

2. **Evaluación interactiva mediante prueba de opción múltiple:**
   * En Copilot Chat, envía la siguiente instrucción para realizar el ejercicio de cierre:
     ```text
     Con base en la Propuesta_Intervencion_Talento.docx y los comunicados generados, actúa como el Director de Ética y Experiencia Humana y evalúa mi comunicación.

     Reglas:
     1. Hazme 3 preguntas consecutivas de selección múltiple (A, B, C, D) sobre adaptación del tono, protección de datos sensibles y claridad de expectativas.
     2. Presenta una pregunta a la vez y espera a que yo responda indicando solo la letra seleccionada.
     3. Entrega retroalimentación inmediata sobre la opción elegida antes de pasar a la siguiente pregunta.
     ```

## Resultado esperado
Dos borradores de correo redactados para distintas audiencias basados en los entregables aprobados y la prueba de opción múltiple completada con retroalimentación inmediata en Copilot Chat.
